# 飞书音频插件 - 倍速播放与下载

一个非官方的开源 Chrome 扩展，为飞书文档音频播放器增加倍速播放和下载按钮。本项目与飞书/Lark 官方无关联。

为 `feishu.cn` 飞书文档中的 HTML 音频播放器添加 `1x / 1.5x / 1.75x / 2x / 3x` 下拉菜单和下载图标。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`feishu-audio-speed-toggle`。
5. 回到飞书文档并刷新页面。

## 说明

这是最小实验版，只声明飞书文档页面权限，不联网、不读取账号数据。下载按钮使用当前播放器的音频地址，并且只在用户点击时触发。飞书若将播放器放在跨域 iframe 内，扩展可能暂时找不到播放器；这种情况需要根据实际 DOM 再做适配。
